# AGENTS.md

Este archivo describe el uso de agentes en este workspace y cómo interactuar con ellos en VS Code.

## ¿Qué es un agente?
Un agente es una entidad automatizada que puede realizar tareas complejas, como búsquedas, análisis de código, generación de archivos, y más, de manera autónoma.

## Uso en VS Code
Cuando inicias un chat con GitHub Copilot en VS Code, este archivo se cargará automáticamente para que tengas acceso a la información sobre agentes y sus capacidades.

## Ejemplo de interacción
- Solicita tareas complejas: "Busca todas las funciones relacionadas con CME en el proyecto."
- Pide generación de archivos: "Crea un resumen de los agentes en AGENTS.md."
- Consulta capacidades: "¿Qué puede hacer un agente en este workspace?"

## Recomendaciones
- Sé específico en tus solicitudes para obtener mejores resultados.
- Puedes pedir que un agente realice búsquedas, edite archivos, genere documentación, y más.

## Contacto
Para dudas o sugerencias, consulta la documentación oficial de VS Code o GitHub Copilot.
